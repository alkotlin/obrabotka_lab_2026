План действий
1) Проектирование архитектуры проекта
  Определить основные модули: физические величины, матрицы/таблицы данных, математическая обработка, графики, ввод-вывод.

2) Создание класса физических величин
  Реализовать хранение значения, размерности, погрешности и единиц измерения.
  Добавить поддержку перевода единиц и проверки совместимости размерностей.
  Реализовать базовые арифметические операции и вычисление погрешностей.
  Создать простейший конструктор для дальнейшей работы над проектом.
  Постепенно расширить конструкторы: из значения, из значения и погрешности, из строки, из другой величины.

3) Работа с матрицами и таблицами данных
  Реализовать класс матрицы/таблицы экспериментальных данных.
  Создать методы добавления, удаления, редактирования строк и столбцов.
  Реализовать доступ к элементам, копирование, очистку и изменение размеров.
  Добавить методы для изменения имеющейся матрицы: вставка, удаление, сортировка, фильтрация.
  Реализовать загрузку и сохранение данных в CSV/JSON.

4) Методы математической обработки данных
  Реализовать базовую статистику: среднее, медиана, дисперсия, СКО, min/max.
  Добавить обработку погрешностей: случайные и приборные погрешности, косвенные измерения.
  Реализовать методы аппроксимации: МНК, линейная и полиномиальная регрессия.
  Добавить расчёт коэффициентов корреляции, неопределённостей и доверительных интервалов.
  Предусмотреть методы проверки гипотез и сравнения экспериментальных данных с теоретическими.

5) Создание класса для работы с графиками
  Реализовать хранение наборов точек, подписей осей, заголовков и легенды.
  Добавить настройки масштаба, сетки, маркеров и линий.
  Реализовать построение графиков по экспериментальным данным.
  Добавить построение теоретических кривых и аппроксимаций.
  Предусмотреть экспорт графиков в изображения или интерактивный вывод.

6) Ввод и вывод данных
  Реализовать консольный ввод физических величин и таблиц.
  Расширить количество методов ввода: из файла, из строки, из CSV/JSON, интерактивно.
  Добавить валидацию ввода и обработку ошибок.
  Реализовать экспорт результатов обработки и отчётов.
7) Тестирование и отладка
  Написать модульные тесты для физических величин, матриц и математических методов.
  Проверить граничные случаи: деление на ноль, несовместимые размерности, пустые данные.
  Добавить примеры лабораторных расчётов для проверки корректност
